A · Split, convert and filter

Turn one line of typed numbers into a list, convert each piece to an int, keep only the ones that pass a test, and print them on one line.

Quick refresher

split(",") cuts one line of text into a list of strings. Strings are not numbers yet, so loop over the list and turn each piece into an int. After that, a for loop with an if keeps only the numbers that pass your test. print(x, end=" ") keeps the results on one line.

numbers = []
for piece in "3,0,-4".split(","):    # split gives a list of strings
    numbers.append(int(piece))       # each string becomes an int
for n in numbers:
    if n > 0:                        # the filter
        print(n, end=" ")

Miami sits low, so a Miami-Dade flood office tracks how high each spot is, in feet. A negative number is below sea level, and 0 is exactly at sea level. Ask for four heights separated by commas. Turn that one line of text into a list of separate strings, then turn each string into an integer. Print the height in INCHES (feet times 12) of only the spots that are ABOVE sea level, with a single space between the results. Notes: every entry will be a whole number, and no functions or exception handling are needed.

How to think about the plan

  1. The user types ONE line of text with the numbers hiding inside it. split(",") cuts that text at each comma and gives back a list of strings.
  2. Strings are not numbers yet. Loop over the list, use int() on each piece, and save the results in a second list. Do the math only after that.
  3. Two for loops, one after the other (not nested): one to convert, one to filter and print. We know how many items are in the list, so for is the right loop.
  4. The filter is one if: height > 0. Zero is AT sea level, not above it, so it is left out.
  5. print(height * 12, end=" ") keeps every result on one line with a single space between them. The heading starts with \n, so a blank line comes first.

Think first

  • What does "-3,0,4,8".split(",") give you: a list of numbers, or a list of text?
  • Why do you need int() before you can ask whether a height is greater than 0?
  • Does 0 count as above sea level? Which comparison keeps it out?
  • Which print comes before the loop, and which one goes inside it?

B · A function that analyzes, and a Y/N loop

The main program collects the text, a function analyzes it and prints, and a loop repeats while the answer is y or Y.

Quick refresher

A function gets what it needs through a parameter, so input() stays in the main program. len() counts characters, a slice like word[0:3] stops BEFORE its end number, and isalnum() is True only when the text is all letters and numbers. input().strip().upper() cleans a typed answer so y, Y and " y " all become Y.

def describe(word):                 # the word comes in as a parameter
    print(len(word), word[0:3])     # length, then the first three characters
    if not word.isalnum():          # isalnum() is True for ONLY letters and numbers
        print("has symbols")

describe("Hi5!")
print("Keep going? (y or n)")
answer = input().strip().upper()    # " y " becomes "Y"

A gym in Doral lets members pick a username at a kiosk. Write a function that takes ONE username and prints three things: how many characters it has, its first three characters (use slicing), and a warning if it contains any symbol. A symbol is anything that is not a letter or a number, and that includes a space. The main program asks for the username, sends it to the function, and then asks whether to check another one. Keep running as long as the answer is y or Y: convert the answer to uppercase so you only have to check for Y. Notes: collect the input in the main program, not in the function. Python can check whether text has only letters and numbers, and you want the opposite of that. All input is valid, with at least three characters, and no exception handling is needed.

How to think about the plan

  1. Two jobs, so two places. The FUNCTION analyzes one username and prints. The MAIN program does the asking and the repeating.
  2. The function gets the username through a parameter, so input() stays in main. It prints its own lines, so it doesn't need a return.
  3. The first three characters are the slice [0:3]: it starts at 0 and stops BEFORE 3.
  4. isalnum() is True when the text has ONLY letters and numbers. We want to warn about the opposite, so the test is if not name.isalnum():.
  5. The repeat is the play-again loop from Part 2: again = "Y" before the while, and ask again as the last thing inside it. input().strip().upper() turns y, Y or " y " into Y.
  6. Several text lines start with \n. Each one prints a blank line first, and that is where the blank lines in the target run come from, even the one at the very top.

Think first

  • Which lines belong to the function, and which stay in the main program?
  • What slice gives the first three characters of "miami305"? Where does the slice stop?
  • isalnum() answers "only letters and numbers?" How do you flip that answer?
  • What value does again need before the loop, and why convert the answer to uppercase?

C · Validate in a function with raise, catch in main

A function asks and checks, and raises your own ValueError for a bad value. The main program keeps asking until a good value comes back, then reports.

Quick refresher

raise ValueError("message") ends the function on the spot, and the return line only runs when the check passed. The code that CALLED the function does the catching: try around the call, except ValueError as err, then print(err). int() raises its own ValueError on text, and the same except catches that one too.

def get_age():
    print("Enter an age:")
    age = int(input())
    if age < 0:
        raise ValueError("Age can't be negative.")
    return age

try:
    age = get_age()
except ValueError as err:
    print(err)

A community theater in Coral Gables has 30 seats in every row, numbered 1 to 30. The constant LAST_SEAT = 30 is given in the plan. Write a function that asks for a seat number and makes sure it is from 1 to LAST_SEAT. If it isn't, raise a custom exception with the error text shown in the output. A valid seat is sent back to the main program. In the main program, keep calling the function while the user keeps typing bad seats, and print the right error message each time. When a good seat arrives, print how many seats are from your seat to the end of the row, two ways: first not counting your own seat, then counting it. Notes: the part of your program that catches your own exception also catches the error int() raises on text, because both are a ValueError. No other kinds of exceptions need to be checked.

How to think about the plan

  1. Two parts, two jobs. The FUNCTION asks and checks. The MAIN program loops and reports. The function never prints the error: it RAISES it.
  2. raise ValueError("text") stops the function on the spot, so the line return seat only runs when the seat passed the check.
  3. Typing letters makes int() raise a ValueError by itself, before your own check even runs. Your raise is also a ValueError, so ONE except ValueError as err: handles both, and print(err) shows whichever message it got.
  4. The try goes around the CALL in main, inside a loop. A flag (asking) becomes False only AFTER the function returned, so a raise skips that line and the loop asks again.
  5. Out of range means too small OR too big, so the check joins two tests with or.
  6. After the loop: the first answer is LAST_SEAT - seat and the second is that number plus 1. The heading starts with \n for a blank line.

Think first

  • Which two kinds of bad input can reach your except? Where does each message come from?
  • Why does the try go around get_seat() in main, and not inside the function?
  • What does the loop do the moment the function raises?
  • Write "outside 1 to LAST_SEAT" in English first, then in Python.

Write a function that asks for the number of people in the group. If the number is below the minimum, raise a custom exception with one message. If it is above the maximum, raise a custom exception with a different message. A valid group size is sent back to the main program. In the main program, keep calling the function until a valid size comes back, and print the message each time. Then print the group's total price. Notes: your except block can print both your own messages and the error Python raises when int() gets text, because both are a ValueError. No other kinds of exceptions need to be checked.

How to think about the plan

  1. Same shape as C1: the function asks, checks and raises, and main loops and reports. The new piece is TWO different messages, so the function has two checks.
  2. Too small and too big each get their own raise ValueError(...) with their own text. An if / elif keeps them apart: below MIN_GROUP, or else above MAX_GROUP.
  3. except ValueError as err: plus print(err) prints whichever message was raised, and Python's own message when someone types a word.
  4. The given values are constants in ALL_CAPS, so the numbers aren't scattered through your code. The price comes from TOUR_PRICE.
  5. The total is the size times the price. The heading starts with \n, and the money line is an f-string with a dollar sign in front: f"${size * TOUR_PRICE}".

MIN_GROUP = 4
MAX_GROUP = 12
TOUR_PRICE = 35

def get_group_size():
    print("How many people are in your group (4 to 12)?")
    size = int(input())
    if size < MIN_GROUP:
        raise ValueError("Too small: a tour needs at least 4 people.")
    elif size > MAX_GROUP:
        raise ValueError("Too big: a boat holds at most 12 people.")
    return size

asking = True
while asking:
    try:
        size = get_group_size()
        asking = False
    except ValueError as err:
        print(err)

print("\nYour group's total price:")
print(f"${size * TOUR_PRICE}")
