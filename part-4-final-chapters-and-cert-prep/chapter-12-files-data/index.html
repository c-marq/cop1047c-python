Chapter 12 Data Files

The Chapter 12 Files notebook reads these three files. Its "run this first" setup cell downloads them into Colab for you. Use this page only if that cell says a download failed.

If the setup cell fails: upload by hand

  1. Click each link below and save the file to your computer. Keep the file name exactly as it is.
  2. In Colab, click the folder icon on the left, then the upload icon, and choose the 3 files.
  3. Run the notebook cells again.
bay_notice.txt
A short notice, 5 lines, for the reading cells.
purchase_amounts.txt
Twelve purchase amounts, one per line, for the sum cell.
python-snake.png
A small picture for the binary cell. The Chapter 11 notebook uses it too.
