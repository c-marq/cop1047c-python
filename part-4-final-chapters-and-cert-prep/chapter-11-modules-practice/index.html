Quick refresher

import math brings in the whole module. You use its names with dot notation: the module name, a dot, then the name, like math.sqrt(81). The prefix keeps the module's names in their own namespace, so a function of your own with the same name does not clash. from math import factorial brings in only that name, and you use it by itself, with no prefix. Python's standard library is the large set of modules that come with Python, such as math and random. There is nothing to install. Packages that do not come with Python need pip first, and none are needed on this page. When a program uses random, its results differ on every run.

import math
from math import factorial

print(math.sqrt(81))
print(math.ceil(2.1))
print(f"{factorial(5):,}")
print(f"{math.cbrt(8):.0f}")

The Calle Ocho domino club in Little Havana is hosting a tournament night. A table seats 4 players, and every player needs a seat. Ask Players: for a whole number. Print Plain division: and the exact result of players / 4, then use math.ceil to work out how many tables the club must set up, and print Tables needed: and that number. With 30 players, plain division gives 7.5 and the club needs 8 tables.

How to think about the plan

  1. import math comes first. After that, every name from the module is used with dot notation: the module name, a dot, then the function name, like math.ceil(...).
  2. input() gives text, so int() goes around it before you divide.
  3. players / 4 gives a decimal. The club cannot set up 7.5 tables.
  4. math.ceil rounds UP to the next whole number. A number that is already whole, like 8.0, stays at 8.

Think first

  • What is 30 / 4, and why can the club not use that answer?
  • Would int(30 / 4) give the right number of tables? Try it in a cell and see.
  • What should the club get for 32 players, which fill 8 tables exactly?

The club scores games on a square board of tiles. Someone at the club once wrote a function named sqrt of their own, and it is already in your plan cell (run it as given). Python's math module also has a function named sqrt. Both can live in one program because each name sits in its own namespace. Import math, set tiles = 49, then print Club function says: with the club's own sqrt(tiles), math module says: with math.sqrt(tiles), and Board side: and tiles with the math square root formatted to 0 decimals (7 tiles).

How to think about the plan

  1. sqrt(tiles) with nothing in front is the function defined in your own program, the main namespace.
  2. math.sqrt(tiles) is a different function. The name before the dot tells Python which namespace to look in.
  3. Having both is not a conflict. The math. prefix is what keeps them apart.
  4. :.0f inside the braces of an f-string shows 0 decimal places, so 7.0 prints as 7.

Think first

  • Which sqrt runs when you write sqrt(49)? Which runs when you write math.sqrt(49)?
  • Why does the math version give 7.0 and not 7?
  • What would change if you imported only the name sqrt from math into this same program?

Add from math import sqrt AFTER the club's def sqrt and the name sqrt now points to the math function, so the club's function is gone from that point on: Club function says: 7.0. Before each game the club draws a tile. A domino tile has two halves, and each half shows 0 to 6 pips, so draw each half with random.randint(0, 6). Then pick who goes first from the club's four players (the list is in your plan) with random.choice. These results are random: your tile and your first player will be different from the sample, and different again every time you run the cell. That is correct. So you can check your work anyway, add a proof: draw 1000 halves, keep the lowest and the highest, and print them. Those last numbers should match the sample every time. Print Your tile: with the two halves, Pips on the tile: and their sum, the first player and goes first, and the proof line.

How to think about the plan

  1. import random first. random.randint(0, 6) includes both ends, so 0 and 6 can both come up.
  2. random.choice(players) picks one item from a list. Give it the whole list as one argument.
  3. You cannot compare random output with the sample. Check it against the rules instead: halves from 0 to 6, a name from the list.
  4. For the proof, start low at the biggest possible half (6) and high at the smallest (0), so the first draw can replace both. Then two if statements inside the loop update them.

Think first

  • Can random.randint(0, 6) give 6? Can it give 0?
  • Your tile is different from the sample. How can you tell your output is still right?
  • Why does the proof start low at 6 and high at 0 and not the other way around?

high = 0

Watch out

The proof line catches range mistakes. With randint(1, 6) no half is ever blank: After 1000 draws, lowest half: 1, highest half: 6. With randint(0, 7) a half of 7 appears, which no domino has: After 1000 draws, lowest half: 0, highest half: 7. random.choice wants one list, not two names: TypeError: Random.choice() takes 2 positional arguments but 3 were given. An empty list gives it nothing to pick: IndexError: Cannot choose from an empty sequence. And without import random: NameError: name 'random' is not defined.

The club buys round tables, and each player needs 60 cm of table edge. The math module is part of Python's standard library: it comes with Python, so there is nothing to install. Python's documentation lists every name in it (the math page of the Python documentation), and you read a line there the same way you read this one. Two names you have not used yet: math.pi is the number pi (3.14159...), a plain value, so no parentheses. math.floor(x) rounds x DOWN to a whole number. The edge of a round table is 2 times pi times the radius. Ask Table radius in cm: (a number that may have decimals), print Edge of the table: with the edge to 0 decimals and cm, then Players who fit (60 cm each): and how many whole 60 cm spaces fit on the edge. A radius of 80 cm gives an edge of 503 cm and 8 players.

How to think about the plan

  1. import math first. math.pi is a value, so it has no parentheses. math.floor(...) is a function, so it does.
  2. float() goes around input(), because the radius may have decimals.
  3. Edge: 2 * math.pi * radius. Seats: the edge divided by 60, rounded DOWN, because a partial space seats nobody.
  4. Print the edge with :.0f. The seat count is already a whole number.

Think first

  • Why floor here, when I1 used ceil?
  • Does math.pi get parentheses? Does math.floor?
  • What are the edge and the seats for a radius of 0?
