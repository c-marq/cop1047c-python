Step 4 · Predict the output

The tricky ones the prep guide warns about. Read the code, say the output out loud, then open the answer.

To run one yourself, copy it into a code cell at colab.new. Every output below came from running that exact code on Python 3.12.

1Mixing types · Objective 2

print(3 + 5.0)
print(3 + "3")
Show the answer
What it prints
8.0
Then the program stops with this error
TypeError: unsupported operand type(s) for +: 'int' and 'str'

Why: Python turns the int into a float on its own when you mix them. It never turns a number into a string, or a string into a number, on its own. Use str() or int() yourself.

2Division · Objective 2

print(10 / 2)
print(10 // 2)
print(type(10 / 2))
Show the answer
What it prints
5.0
5
<class 'float'>

Why: / always gives a float, even when it divides evenly. // gives the floor, and two ints give an int.

3round() · Objective 5

print(round(5.9))
print(round(5.88, 1))
print(round(2.5))
Show the answer
What it prints
6
5.9
2

Why: With no second number, round gives an int. With 1, you get one decimal place. Bonus: Python rounds a half to the nearest even number, so 2.5 becomes 2.

4Type hints · Objective 5

def double(n: int) -> int:
    return n * 2

print(double("ha"))
Show the answer
What it prints
haha

Why: n: int is a hint for people, not a rule. Python ran it with a string and repeated it.

5and before or · Objective 3

print(True or False and False)
print((True or False) and False)
Show the answer
What it prints
True
False

Why: and goes first. The first line is True or (False and False), which is True. Parentheses change the order.

6Truthiness · Objective 3

if "0":
    print("A")
if []:
    print("B")
if " ":
    print("C")
if 0.0:
    print("D")
Show the answer
What it prints
A
C

Why: Any non-empty string is True, even "0" and " ". An empty list and 0.0 are False.

7The ternary (one-line if) · Objective 3

a = 8
b = 3
biggest = a if a > b else b
print(biggest)
Show the answer
What it prints
8

Why: The shape is value_if_true if condition else value_if_false. 8 > 3 is True, so biggest is a.

8range stops before the end · Objective 4

for i in range(2, 5):
    print(i, end=" ")
print()
print(list(range(3)))
Show the answer
What it prints
2 3 4 
[0, 1, 2]

Why: range(2, 5) gives 2, 3 and 4. range(3) starts at 0 and gives 0, 1, 2.

9ValueError or TypeError? · Objective 9

for item in ["a", [1, 2, 3]]:
    try:
        int(item)
    except ValueError:
        print("ValueError")
    except TypeError:
        print("TypeError")
Show the answer
What it prints
ValueError
TypeError

Why: int("a") is the right type (a string) with a bad value, so ValueError. int([1, 2, 3]) is the wrong type, so TypeError.

10sort() or sorted()? · Objective 6

nums = [3, 1, 2]
result = nums.sort()
print(result)
print(nums)
copy = sorted([9, 7, 8])
print(copy)
Show the answer
What it prints
None
[1, 2, 3]
[7, 8, 9]

Why: sort() changes the list and returns None, so result is None. sorted() leaves the original alone and returns a new list.

11append or extend? · Objective 6

a = [1, 2]
a.append([3, 4])
print(a)
b = [1, 2]
b.extend([3, 4])
print(b)
Show the answer
What it prints
[1, 2, [3, 4]]
[1, 2, 3, 4]

Why: append adds its argument as ONE item, even a list. extend adds each item of the list.
