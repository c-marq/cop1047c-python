Ch 12 · zyBooks Chapter 12 · Write a file, read it back line by line, compare text, and add to a file without erasing it.

Quick refresher

open(name, "w") writes (and erases). open(name, "a") adds to the end. readlines() gives a list of lines, and every line keeps its newline until you strip() it. write() takes text only and adds no newline. Close a file before you read what you wrote.

f = open("notes.txt", "w")
f.write("Ana\nLuis\n")
f.close()

f = open("notes.txt")
lines = f.readlines()
f.close()
print(lines)
print(lines[0].strip())
['Ana\n', 'Luis\n']
Ana

A marina keeps its boat names in a file, one per line (the plan writes the file for you). Ask Cutoff boat name: . Read the file with readlines(). For each boat, print the name and - up to the cutoff if the name sorts at or before the cutoff, or - after the cutoff if it sorts after it. Count the ones up to the cutoff and print Up to Marlin: 2 at the end (with the typed cutoff in place of Marlin).

How to think about the plan

  1. The file is already written. Open it again to read, use readlines(), and close it.
  2. Each line still has its newline. line.strip() gives the plain name.
  3. Text compares with <= the way words sort in a dictionary: capitals sort before lowercase, so every name here starts with a capital.
  4. A counter starts at 0 before the loop and goes up by 1 for every name up to the cutoff. The summary prints once, after the loop.

Think first

  • What does "Marlin\n" == "Marlin" give?
  • What does the count do if the cutoff comes before every name?
  • Why does the summary line go after the loop, at the left edge?

cutoff = input("Cutoff boat name: ")

f = open("boats.txt")
lines = f.readlines()
f.close()

count = 0
for line in lines:
    name = line.strip()
    if name <= cutoff:
        print(name, "- up to the cutoff")
        count += 1
    else:

print("Up to", cutoff + ":", count)

Watch out

Forget strip() and the newline rides along. Each name prints with a line break in the middle, and typed Marlin counts only Up to Marlin: 1 because "Marlin\n" is after "Marlin". A driver writes down the toll for each trip, one amount per line, in a file (the plan writes it). Read it with readlines(). Print Trips: and how many lines there are, Total: $60 with the sum, and Average: $12.00 with 2 decimals.

How to think about the plan

  1. Read all the lines. len(lines) is the number of trips.
  2. Each line is text with a newline. int(line) turns it into a number and ignores the newline.
  3. A total starts at 0 before the loop and grows inside it.
  4. The average is the total divided by the number of trips. :.2f gives 2 decimals.

Think first

  • What does int("10\n") give?
  • What happens to the average if the file is empty?
  • Which lines go inside the loop, and which go after it?

A rental desk keeps each rental as one line: an item, a space, and the hours (the plan writes the file). Read it with readlines(). Make a new file, report.txt, with one line per rental like Kayak - Short: 4 or more hours is Full day, 2 or 3 hours is Half day, and less is Short. Then open the report, print what is in it, and print Total hours: with the sum.

How to think about the plan

  1. Read the rentals first. Open report.txt in "w" mode and keep it open while you loop.
  2. line.split() cuts a line into the item and the hours. The hours need int().
  3. One decision per line: if, elif, else.
  4. report.write(name + " - " + category + "\n") writes text and the Enter. Close the report, then open it again to read it.

Think first

  • What happens at exactly 4 hours? Which comparison do you need?
  • Why does write() need a "\n" added by you?
  • Why close the report before reading it back?

f.write("Paddleboard 5\nKayak 1\nCanoe 3\nSailboat 6\n")

report = open("report.txt", "w")
total = 0
for line in lines:
    parts = line.split()
    name = parts[0]
    hours = int(parts[1])
    total += hours
    if hours >= 4:

    elif hours >= 2:
        category = "Half day"
    else:
        category = "Short"
    report.write(name + " - " + category + "\n")
report.close()

f = open("report.txt")
print(f.read(), end="")
f.close()
print("Total hours:", total)

A dock keeps a log file with one entry per line (the plan writes three entries). Ask New log entry: . Print how many lines the log has Before:, add the entry to the END of the file, then print how many lines it has After: and the last line, like Last line: Dock closed.

How to think about the plan

  1. Read the file with readlines() to count the lines before.
  2. Open it in "a" mode. Write the entry and a newline, then close it.
  3. Read the file again. The count is one more, and the last item is the new entry.
  4. lines[-1] is the last line. It still has its newline, so strip() it.

Think first

  • What would "w" do to the three old entries?
  • Why does the entry need a newline of its own?
  • Why read the file again after closing?

A guest list is a file with one name per line (the plan writes it). Ask Guest name: . Read the file with readlines() and look through the lines in order. If a line matches the typed name exactly, print Found on line 3 (with the real line number, counting from 1) and stop looking. If no line matches, print the name and is not on the list.

How to think about the plan

  1. Read all the lines, then walk through them with a counter that starts at 0 and goes up by 1 on each pass.
  2. Compare line.strip() with the typed name. Without strip() the newline makes every name a mismatch.
  3. When there is a match: print, set a flag found = True, and break.
  4. After the loop, the flag decides whether to print the "not on the list" line.

Think first

  • What does the flag remember while the loop runs?
  • Does "luis" match "Luis"? Why or why not?
  • Why print the not-found message after the loop, not inside it?
