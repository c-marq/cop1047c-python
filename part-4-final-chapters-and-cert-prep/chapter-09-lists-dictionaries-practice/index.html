Quick refresher

A list keeps items in order and can change: append, remove, pop, insert, count. sort() changes a list and returns nothing; sorted() returns a new one. get(key, default) reads a dictionary without a KeyError.

sales = [200, 100, 300]
sales.append(400)
print(sales, sorted(sales, reverse=True))
menu = {"taco": 4}
print(menu.get("pizza", 0))
[200, 100, 300, 400] [400, 300, 200, 100]
0

A food truck in Wynwood keeps its pickup line in a list (it's in the plan). Ask Who is leaving the line? . If that name is in the line, print how many times it appears, like Ana is in line 3 times, and remove only the FIRST one. If not, print the name and is not in line. Either way, Sam joins at position 1. Then print the line.

How to think about the plan

  1. count tells how many times a name appears. remove takes out only the first match.
  2. A name that isn't in the list makes remove crash, so check with in first.
  3. insert(1, "Sam") puts Sam BEFORE whoever is at position 1 now.
  4. Insert and print happen either way, so they go after the if and else, not inside them.

Think first

  • What does remove do when the name isn't in the list?
  • Should you count before or after you remove? Try both and compare.
  • Where does insert(1, "Sam") put Sam: before or after the item at position 1?

name = input("Who is leaving the line? ")

    line.remove(name)
else:

line.insert(1, "Sam")

Watch out

Skip the in check and a name that isn't there crashes: ValueError: list.remove(x): x not in list. And count BEFORE you remove: counting after the remove prints 2, not 3 (Ana is in line 2 times).

A Wynwood food truck owner types one line with every night's sales, separated by spaces, like 200 100 300. Ask Sales for each night, separated by spaces: , turn each piece into a float, and keep them in a list. Print the best night with a dollar sign and 2 decimals, like Best night: $300.00, and the average night the same way, like Average night: $200.00.

How to think about the plan

  1. An empty list (sales = []) collects the numbers, one append per piece.
  2. text.split() cuts the typed line at the spaces into a list of pieces. Extra spaces don't matter.
  3. Each piece is still text. float(part) turns it into a number BEFORE it goes in the list, so decimals like 250.5 work too.
  4. max(sales) is the best night. sum(sales) / len(sales) is the average. :.2f gives 2 decimals.

Think first

  • What does "200 100 300".split() give you? Try it in a cell.
  • Why float() and not int()? What would int("250.5") do?
  • What happens if someone types an empty line?

Watch out

Forget float() and the list holds text, so the format fails: ValueError: Unknown format code 'f' for object of type 'str'. Use int() and a decimal like 250.5 fails: ValueError: invalid literal for int() with base 10: '250.5'. And an empty line gives ValueError: max() iterable argument is empty.

A food truck types one line with the number of customers on each night, like 7 3 4 9 12 5 8, then a second answer to Smallest busy night? (a whole number). Build a new list of the nights with at least that many customers, sort it from busiest to slowest, and print it on ONE line after Busy nights:, each number followed by a space. Then print the top three using a slice, like Top three: [12, 9, 8].

How to think about the plan

  1. Read the line the way you did in F2, but each piece goes through int().
  2. Build a NEW list (busy) with append instead of removing from customers. Removing while looping skips items.
  3. busy.sort(reverse=True) puts the busiest first. It changes the list and returns nothing.
  4. print(night, end=" ") keeps the next print on the same line, with a space after each number. A bare print() at the end finishes the line.
  5. busy[:3] is the first three. A slice of a short list never crashes.

Think first

  • Why not remove the small numbers from customers itself?
  • What does sort(reverse=True) return?
  • What should the top three look like when no night is busy enough?

text = input("Customers each night, separated by spaces: ")
customers = []
for part in text.split():
    customers.append(int(part))
minimum = int(input("Smallest busy night? "))
busy = []
for night in customers:
    if night >= minimum:
        busy.append(night)
busy.sort(reverse=True)
print("Busy nights:", end=" ")
for night in busy:
    print(night, end=" ")
print()
print("Top three:", busy[:3])

Watch out

Removing the small ones from customers while you loop leaves one behind, because 3 and 4 sit side by side. For 6 it prints Busy nights: 12 9 8 7 4 , and that 4 does not belong. Forget int() and the comparison fails: TypeError: '>=' not supported between instances of 'str' and 'int'. Forget the bare print() and the next line joins the numbers: Busy nights: 12 9 8 7 Top three: [12, 9, 8]. The spaces after the numbers are real, even though Colab doesn't show them.

Three trucks sold on three nights. Each row of the list is one truck and each column is one night (it's in the plan). Every truck got a $50 tip on its LAST night. Add 50 to the last number in every row and print the whole list. Then print each truck's total like Truck total: 650.

How to think about the plan

  1. sales[i] is the whole row for truck i. sales[i][-1] is that truck's last night.
  2. A loop over range(len(sales)) visits every row number.
  3. -1 means the last item, whatever the length.
  4. A second loop over the rows prints sum(row) for each truck.

Think first

  • What is sales[1]? What is sales[1][-1]?
  • Why is += used here and not = ?
  • Which loop do you need to change the list, and which to just read it?

A food truck's menu is a dictionary (it's in the plan). Add flan for 3 dollars. Ask Which item? and print the price like arepa costs $5, or Not on the menu. Then print Menu board: and every item with its price, A to Z ignoring upper and lower case. Last, Batido sells out: remove it, print Sold out: Batido ($6), and print how many items are left.

How to think about the plan

  1. menu["flan"] = 3 adds a new key.
  2. menu.get(item, 0) gives 0 instead of a KeyError when the item isn't there. A real price is never 0, so 0 means "not on the menu".
  3. list(menu.keys()) makes a list of the names. names.sort(key=str.upper) sorts it ignoring case. Then menu[name] is each price.
  4. menu.pop("Batido", 0) removes the item and gives back its price. len(menu) counts what is left.

Think first

  • What does menu["pizza"] do? What does menu.get("pizza", 0) do?
  • Why does "Batido" need key=str.upper to land in the right place?
  • Should you sort before or after Batido sells out?

menu = {"taco": 4, "Batido": 6, "arepa": 5}

menu["flan"] = 3
item = input("Which item? ")
price = menu.get(item, 0)
if price == 0:
    print("Not on the menu")
else:
    print(f"{item} costs ${price}")
print("Menu board:")
names = list(menu.keys())
names.sort(key=str.upper)
for name in names:
    print(name, menu[name])
sold_out = menu.pop("Batido", 0)
print(f"Sold out: Batido (${sold_out})")
print("Items left:", len(menu))
